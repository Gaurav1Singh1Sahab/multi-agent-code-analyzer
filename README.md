# Multi-Agent Code Analysis & Documentation System

## Objective

Analyze source code repositories using multiple AI agents and generate:

- Technical Documentation
- PM Documentation  
- Architecture Understanding
- Code Insights

## Tech Stack

- FastAPI
- Streamlit
- LangGraph
- OpenAI
- Langfuse
- GitHub Integration
- SQLite (initially)
- PostgreSQL (later)

## Milestones

- M1: Authentication & Project Registration
- M2: Repository Ingestion
- M3: Code Parsing
- M4: Multi-Agent Workflow
- M5: Documentation Generation
- M6: PM Analysis
- M7: SDE Analysis
- M8: Reporting & Export
